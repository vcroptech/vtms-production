Two cancellation types — which do I send?

📅 All Classes Cancelled — date range

Use when the whole school day is off for one or more teachers — a holiday, an event, closure for a range of dates.

One school, one or more teachers (checkbox list or "All teachers"), a from/to date, and a single school start time used to measure notice for every day in the range.

📌 Particular class — specific

Use when only one class/section for one teacher on one date is cancelled — everything else that day goes ahead normally.

One school, one teacher, subject, class, section, exact scheduled date and time.

ⓘOnly Head Teacher, Org Admin and vCrop Admin can send a cancellation. Cluster Coordinator is notified automatically whenever one is sent for their school, but the Cancellations screen itself isn't in their menu at all — they can't open it to browse the list. Teachers only ever see their own records.
What happens when you send one

The affected teacher(s), the school's Cluster Coordinator (if assigned), Org Admin and vCrop Admin are all notified immediately. On the teacher's own Mark Attendance form, if the date (and for a specific cancellation, the exact class/section) matches, Class status is auto-locked to Cancelled with a red explanation note — the teacher doesn't get a choice on that row, so make sure the details you enter are correct before sending.

⚠Overlap handling for date ranges: if part of a newly requested range is already covered by an earlier cancellation for that same teacher at that school, only the genuinely new, not-yet-covered days are sent as a fresh record — the rest is silently skipped rather than duplicated. If a teacher's entire requested range turns out to already be fully covered, that teacher is skipped entirely and you'll see exactly who in the confirmation message. If every selected teacher is already fully covered, nothing is sent at all.
